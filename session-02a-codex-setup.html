Cho nó làm bài kiểm tra

Tôi đang chuẩn bị build một tool cho HWM.

1. Liệt kê các Skill và tool bạn đang có thể dùng cho bài này.
2. Đọc Bộ hồ sơ build của team, rồi kể lại workflow hiện tại:
   ai làm, từng bước, tool, input, output và điểm bàn giao.
3. Chỉ ra context còn thiếu. Chưa được tự đoán.
4. Đề xuất cách tiếp cận chỉ đọc trước; chưa ghi, gửi hay publish.
5. Nêu một bài test nhỏ có thể chạy ngay để chứng minh setup đang hoạt động.
Qua bài = biết dùng gì + đọc đúng context + hỏi đúng chỗ thiếu + chưa tự ý hành động
